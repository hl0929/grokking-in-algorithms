准备计算。斐波那契数列的迭代解法通过维护两个变量 a 和 b，在每次循环中将其向后推进，从而避免了递归带来的重复计算。

Iteration Logic O(N) Time / O(1) Space
def fib(n):
if n < 2: return n
a, b = 0, 1
for _ in range(n - 1):
# 核心更新
a, b = b, a + b
return b

关键步骤说明

  • 1. 初始 a=0, b=1 代表 F(0) 和 F(1)。
  • 2. 每次循环，b 的旧值给 a，a+b 的新值给 b。
  • 3. 这相当于在数轴上向右滑动。
