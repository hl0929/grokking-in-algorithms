```python
def fib(n):
    if n < 2:
        return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b


n = 4
result = fib(n)
print(result)
```

这道题目（LeetCode 509. 斐波那契数）的核心思想是 **“动态规划的滚动优化（Space-Optimized Dynamic Programming）”**。

在算法的学习路径上，斐波那契数列是从**递归**转向**递推**的最佳阶梯。如果说递归是在“由果溯因”，那么这段代码就是在“脚踏实地，步步为营”。

---

### 一、 核心思想：丢掉沉重的历史

斐波那契数列的规则是 $F(n) = F(n-1) + F(n-2)$。
1.  **记忆的局限性**：虽然计算第 $n$ 个数需要前面的信息，但其实你**只需要知道前两个**就够了。
2.  **滚动前进**：想象你在大地上跳跃，为了跳到下一个点，你只需要前两步作为支撑。一旦跳到了新位置，更早之前的那个脚印就不再重要了，可以被“擦除”。
3.  **状态压缩**：我们不需要开辟一个巨大的数组来存所有的历史记录，只需要两个变量不断交替更新。

---

### 二、 算法逻辑：变量的接力赛

#### 1. 基础特判
*   `if n < 2: return n`：这是数列的起点。$F(0)=0, F(1)=1$。如果没有这两块基石，后面的高楼就建不起来。

#### 2. 状态转移（变量滚动）
*   `a, b = 0, 1`：`a` 代表“爷爷”，`b` 代表“爸爸”。
*   `for _ in range(n - 1)`：
    *   `a, b = b, a + b`：
        *   新的 `a` 变成了原来的“爸爸”。
        *   新的 `b` 变成了“爷爷 + 爸爸”的和（也就是“孙子”）。
    *   这个过程在 Python 里通过元组赋值一气呵成，不需要中间变量 `temp`，极其优雅。

#### 3. 最终产出
*   循环结束后，`b` 总是指向当前序列中最年轻、最新的那个数字。

---

### 三、 过程模拟 (`n = 4`)

1.  **初始**：`a = 0, b = 1`。
2.  **第 1 次循环**：
    *   `a` 变成 1，`b` 变成 0 + 1 = 1。 (此时 $F(2) = 1$)
3.  **第 2 次循环**：
    *   `a` 变成 1，`b` 变成 1 + 1 = 2。 (此时 $F(3) = 2$)
4.  **第 3 次循环**：
    *   `a` 变成 2，`b` 变成 1 + 2 = 3。 (此时 $F(4) = 3$)
5.  **结果**：3。

---

### 四、 复杂度分析

*   **时间复杂度：$O(N)$**
    *   只需要从头到尾走一遍，没有任何重复计算。相比递归解法的 $O(2^N)$，这简直是从牛车换成了火箭。
*   **空间复杂度：$O(1)$**
    *   无论 `n` 有多大，我们始终只用了 `a` 和 `b` 两个空间。这是空间优化的极致。

---

### 五、 总结金句

> **“这叫‘心无旁骛，迭代常新’。斐波那契数列的迭代解法教会了我们一个深刻的道理：虽然未来由过去决定，但我们并不需要背负所有的过去前行。通过对状态的不断‘滚动’与‘覆盖’，我们把复杂的递归树剪枝成了一条直线。这种对内存空间的克制与对逻辑链路的精简，正是动态规划最迷人的初级形态。”**
